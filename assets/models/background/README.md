# Floating island backdrop

The optimized production GLB is stored here with this exact filename:

`floating_island_hero.glb`

`CONFIG.distantRange.floatingIslandBackdrop.enabled` currently enables the
authored 1+3 cluster. The game treats it as optional background scenery: it
loads asynchronously, has no collision or save data, and a missing/failed GLB
does not stop Liora Farm from booting.

See `docs/FLOATING-ISLAND-TUNE2.md` before changing its framing, scale or fog.
