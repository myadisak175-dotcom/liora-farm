# Legacy standalone assets

This directory is retained only for older standalone Builder test pages that still use historical relative paths.

Canonical production assets now live under:

- `assets/models/builder/`
- `assets/models/player/`
- `assets/textures/`
- `assets/catalog.json`

Do not add new production Meshy exports here. New assets should be added to the canonical `assets/` tree and registered through the catalog/config layer.
